# Тут хранятся модели

| Файл | Описание |
|---|---|
| `best_model_simple.pth` | Сохранённая версия простой модели глубокого обучения. Использовалась в базовом эксперименте с последовательными сигналами/окнами данных. Может применяться для быстрой проверки работоспособности пайплайна и сравнения с более сложной моделью. |
| `best_model_complex.pth` | Сохранённая версия более сложной модели глубокого обучения. Использовалась в расширенном эксперименте с более сложной архитектурой и/или более информативным набором входных признаков. Предназначена для сравнения качества с простой моделью и классическими ML-подходами. |
