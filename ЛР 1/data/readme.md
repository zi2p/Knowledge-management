## В этой папке хранятся данные, полученные при обработке датасета.

# Описание CSV/NPZ-файлов с результатами экспериментов

| Файл | Краткое описание |
|---|---|
| `deep_learning_comparison_results.csv` | Сводная таблица сравнения deep learning модели 1D CNN с baseline и лучшей классической моделью ExtraTrees. Содержит метрики MAE, RMSE, долю ошибок меньше 5 и 10 BPM. |
| `hr_rgb_features_source1.csv` | Набор простых RGB-признаков, извлечённых из видео `source1`. Использовался для базового эксперимента с признаками `R_mean`, `G_mean`, `B_mean`, `R_std`, `G_std`, `B_std`. |
| `hr_rgb_features_source1_all.csv` | Полный датасет RGB-признаков для всех обработанных видео из `source1`. Использовался для обучения и проверки базовой модели на RGB-признаках. |
| `hr_rgb_features_source1_extended.csv` | Расширенный датасет RGB-признаков для `source1`, включающий дополнительные статистики: минимум, максимум, медиану и размах по RGB-каналам. |
| `hr_rppg_window_features_improved.csv` | Улучшенный датасет оконных rPPG/RGB-признаков. Содержит признаки, рассчитанные по временным окнам после выделения ROI и применения POS-алгоритма. |
| `hr_rppg_window_features_source1.csv` | Датасет rPPG/RGB-признаков для видео из `source1`. Использовался для проверки качества модели на одном источнике данных. |
| `hr_rppg_window_features_source2.csv` | Основной датасет rPPG/RGB-признаков для `source2`. На нём был получен лучший основной результат с моделью ExtraTrees. |
| `hr_rppg_window_features_source3.csv` | Датасет rPPG/RGB-признаков для видео из `source3`. Использовался в экспериментах с объединением нескольких источников. |
| `hr_rppg_window_features_source4.csv` | Датасет rPPG/RGB-признаков для `source4`. Использовался для проверки возможности тестирования на отдельном источнике, однако мог содержать пустые или неполные данные после фильтрации окон. |
| `improved_model_results.csv` | Таблица результатов улучшенного эксперимента с rPPG-признаками и несколькими моделями. Содержит сравнение моделей по MAE, RMSE и проценту попаданий в допустимую ошибку. |
| `improved_results_source2_engineered.csv` | Результаты эксперимента на `source2` после добавления engineered features и подбора параметров. Использовался для проверки, улучшает ли расширение признаков качество модели. |
| `model_results.csv` | Общая таблица результатов ранних моделей, включая базовые RGB-эксперименты и сравнение вариантов разбиения данных. |
| `model_results_source2.csv` | Основная таблица результатов для `source2`: baseline, ExtraTrees, RandomForest и HistGradientBoosting. Используется как главный результат работы. |
| `results_group_split_all_collected.csv` | Результаты эксперимента на объединённых данных с разделением по сессиям. Использовался для оценки устойчивости модели на более разнородных данных. |
| `rppg_windows_dataset.npz` | Сжатый NumPy-датасет с окнами rPPG/green-сигналов для deep learning эксперимента. Используется как вход для 1D CNN. |
| `summary_experiments_results.csv` | Итоговая сводная таблица всех проведённых экспериментов. Содержит основные метрики и краткие комментарии по каждому варианту модели. |
