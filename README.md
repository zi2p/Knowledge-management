## Лабораторная работа 3

### Получение знаний из одного источника OpenLinkedData с использованием языка запросов SPARQL

#### Теория

Для баз знаний существует свой язык запросов SPARQL. Основные конструкции и примеры запросов представлены в стандарте (https://www.w3.org/TR/sparql11-query/). Подразумевается что источники данных в открытом доступе и в запросе мы указываем каким условиям должны удовлетворять требуемые данные. Семантика запросов многим напоминает SQL, так как в основе находится декларативность: определяется “что” нужно, а не “как” это получить. В запросе SPARQL можно указать откуда брать данные, как фильтровать, какие операции провести с данными и многое другое. Возвращаемый результат называется таблицей решений (solution table) и представляется в формате таблицы. Основу запроса представляет собой тройки (triplet https://en.wikipedia.org/wiki/Semantic_triple): субъект, предикат, объект. Граф состоит из элементов (субъект, объект) и связей (предикат) между ними, иными словами описывается каким требованиям должен удовлетворять граф, чтобы попасть в таблицу решений.

Пример запроса:

```
# Запрос возвращает названия графов и значения объектов для переменных,
# в которых два предиката имеют заданные значения.
SELECT ?субъект_1 ?объект_3
WHERE
{
 # Граф вида:
 # субъект_1 -(предикат_1)-> объект_1
 # субъект_1 -(предикат_2)-> объект_2
 # субъект_1 -(предикат_3)-> (набор объектов)
 ?субъект_1 предикат_1 объект_1 .
 ?субъект_1 предикат_2 объект_2 .
 ?субъект_1 предикат_3 ?объект_3 .
}

```

#### Wikidata https://query.wikidata.org/

```
# Вывод всех троек, которые относятся к классу котов
SELECT ?item ?itemLabel
WHERE {
 # wdt:P31 — instance of Свойство, обозначающее класс объекта
 # wd:Q146 — cat
 ?item wdt:P31 wd:Q146 .
 # Helps get the label in your language, if not, then en lang
 SERVICE wikibase:label {
 bd:serviceParam wikibase:language "ru,en" .
 }
}

```

#### DBpedia https://dbpedia.org/sparql

```
PREFIX dbo: <http://dbpedia.org/ontology/>
PREFIX dbr: <http://dbpedia.org/resource/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?airport ?airportName ?city ?cityName
WHERE {
 VALUES ?city { dbr:Berlin dbr:Munich }
 ?airport a dbo:Airport ;
 dbo:city ?city ;
 rdfs:label ?airportName .
 ?city dbo:country dbr:Germany ;
 rdfs:label ?cityName .
 FILTER(LANG(?airportName) = "en")
 FILTER(LANG(?cityName) = "en")
}
ORDER BY ?cityName ?airportName
LIMIT 50
```
